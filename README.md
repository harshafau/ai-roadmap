# AI Career Roadmap

A comprehensive one-month roadmap to prepare for AI-related job roles, focusing on Prompt Engineering, AI Automation, and AI Agent development.

## Features

- **Interactive Progress Tracking**: Track your progress in technical skills, projects, and job preparation.
- **Weekly Schedule**: Detailed day-by-day plan for a month of learning.
- **Learning Resources**: Curated list of resources for each skill area.
- **Project Templates**: Ready-to-use templates for portfolio projects.
- **Job Application Tracker**: Keep track of your job applications.
- **Dark Mode**: Toggle between light and dark themes.
- **Data Export/Import**: Save and load your progress.

## Technologies Used

- HTML5
- CSS3 (with CSS Variables)
- JavaScript (Vanilla)
- Local Storage for data persistence
- Font Awesome for icons

## Getting Started

1. Visit the [AI Career Roadmap](https://harshafau.github.io/ai-roadmap/)
2. Start tracking your progress by checking off completed skills
3. Follow the weekly schedule to structure your learning
4. Use the export feature to regularly back up your progress

## Development

To run this project locally:

```bash
git clone https://github.com/harshafau/ai-roadmap.git
cd ai-roadmap
# Open index.html in your browser
```
