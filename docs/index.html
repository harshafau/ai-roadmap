Project Templates

Project 1: Advanced Prompt Engineering Portfolio

Objective: Demonstrate your prompt engineering skills across different use cases

Components

  • Collection of optimized prompts for different tasks
  • Comparison of different prompting techniques
  • Performance metrics and analysis
  • User interface for testing prompts

Technologies

  • OpenAI API / Anthropic API
  • Python
  • Streamlit (optional)

Project 2: RAG-based Knowledge Assistant

Objective: Build a system that answers questions based on custom documents

Components

  • Document processing pipeline
  • Vector database for storage
  • Retrieval mechanism
  • Response generation with citations
  • Simple web interface

Technologies

  • LangChain or LlamaIndex
  • Vector database (Chroma, FAISS)
  • OpenAI API
  • Streamlit

Project 3: AI Automation Workflow

Objective: Create an automated workflow that uses AI to process and transform data

Components

  • Data collection from multiple sources
  • AI processing (classification, extraction, summarization)
  • Automated actions based on AI output
  • Monitoring and reporting

Technologies

  • n8n, Make, or similar
  • OpenAI API
  • Python scripts
  • Web APIs
